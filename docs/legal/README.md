# Documentacao LGPD - Pacote para Juridico

Este diretorio contem os documentos base para o juridico redigir e homologar os textos oficiais da plataforma:

1. 01-dossie-lgpd-sistema.md
- visão consolidada do tratamento de dados no sistema;
- controles implementados;
- evidencias tecnicas e gaps.

2. 02-matriz-dados-pessoais-lgpd.md
- inventario de dados pessoais (RoPA simplificada);
- finalidades, bases legais sugeridas e compartilhamentos.

3. 03-questionario-juridico-termos-e-politica.md
- questionario objetivo para fechamento de termos e politica de privacidade.

## Ordem sugerida de uso
1. Ler o dossie tecnico.
2. Validar/ajustar a matriz de dados com juridico e DPO.
3. Responder o questionario para fechar textos finais.
4. Publicar versoes oficiais em producao e registrar versao/data.
